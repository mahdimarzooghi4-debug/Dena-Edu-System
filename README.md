# دنا — Dena Edu System

دنا (دانش‌آموزان نوآفرین ایران) بستر فنی دسترسی به آموزش ضبط‌شده، تمرین و آزمون است؛ مؤسسه یا ارائه‌دهندهٔ مجاز مسئول محتوا و خدمات آموزشی مربوط است. تأیید مدارک مؤسسه توسط دنا صرفاً برای دسترسی به پلتفرم است، نه صدور مجوز آموزشی.

**Technology decision:** Next.js App Router + React + TypeScript; Tailwind CSS + shadcn/ui with RTL Persian; PostgreSQL + Drizzle ORM; Better Auth; Zod + React Hook Form; Vitest + Playwright.

**Design reference:** https://www.figma.com/design/8Bo8BNS5LVQfTJhxwCYQmo/Dena-Ecosystem

Repository initialized for the implementation scaffold. Application code and local development instructions are being prepared on the `chore/bootstrap-dena-stack` branch.
