# فهرست و استخراج کتاب‌های درسی

فهرست اولیه بر اساس پایگاه رسمی کتاب‌های درسی ساخته می‌شود. هر سطر `catalog-v1.jsonl` یک عنوان و ویرایش مستقل است. `sourcePageUrl` و `pdfUrl` باید از دامنهٔ رسمی chap.sch.ir باشند؛ این فایل فقط فراداده است و متن کتاب را نگه نمی‌دارد. Snapshot فعلی ۲۱ ورودی دارد؛ ۱۲ مورد پیوند مستقیم PDF رسمی و ۹ مورد صفحهٔ رسمیِ کتاب هستند. پوشش هنوز کامل نیست.

عناوین رسمی در این snapshot برای سال ۱۴۰۵–۱۴۰۶ ثبت شده‌اند؛ برای نمونه PDF فارسی سوم: https://chap.sch.ir/sites/default/files/lbooks/1405-1406/10/C303.pdf .

## استخراج محلی

پیش‌نیاز: `pdftotext` از Poppler روی سیستم نصب باشد. خروجی متن و PDF به‌صورت محلی و بیرون از مخزن ذخیره می‌شود:

```sh
node scripts/ingest-dena-textbooks.mjs \
  --catalog data/ai/textbooks/catalog-v1.jsonl \
  --book fa-01-1405-1406 \
  --output /srv/dena-private/textbooks
```

برای افزودن کتاب، پیوند PDF رسمی را در `pdfUrl` وارد کنید. ابزار دامنه و مسیر رسمی را بررسی می‌کند، PDF را دریافت و SHA-256 را محاسبه می‌کند، متن را با حفظ صفحه به `pages.jsonl` تبدیل می‌کند و manifest محلی شامل نسخه، زمان دریافت و hash می‌سازد. فایل‌های حجیم یا استخراج‌شده نباید به Git افزوده شوند.

## پوشش فهرست

فهرست با نسخهٔ سال تحصیلی و برای هر کتاب جداگانه گسترش می‌یابد: پیش‌دبستانی؛ پایه‌های ۱ تا ۶ ابتدایی؛ پایه‌های ۷ تا ۹ متوسطهٔ اول؛ پایه‌های ۱۰ تا ۱۲ متوسطهٔ دوم نظری و شاخه‌های فنی‌وحرفه‌ای/کاردانش؛ و نسخه‌های مناسب‌سازی‌شدهٔ آموزش استثنایی. اینها دامنهٔ گردآوری هستند و عنوان‌ها باید مستقیماً از پایگاه رسمی ثبت شوند.
