# فهرست و استخراج کتاب‌های درسی

فهرست اولیه بر اساس پایگاه رسمی کتاب‌های درسی ساخته می‌شود. هر سطر `catalog-v1.jsonl` یک عنوان و ویرایش مستقل است. URL صفحهٔ رسمی باید با صفحهٔ کتاب در `chap.sch.ir` منطبق باشد؛ `pdfUrl` را از همان صفحه ثبت کنید. این فایل فقط فراداده است و متن کتاب را نگه نمی‌دارد. در این snapshot ده عنوان رسمیِ نمونه از ابتدایی، متوسطهٔ اول، متوسطهٔ دوم نظری، فنی‌وحرفه‌ای و آموزش استثنایی ثبت شده‌اند؛ این هنوز فهرست کامل عناوین نیست.

عناوین رسمی در این snapshot برای سال ۱۴۰۵–۱۴۰۶ ثبت شده‌اند؛ برای نمونه «فارسی (اول)»: https://www.chap.sch.ir/books/14143 .

## استخراج محلی

پیش‌نیاز: `pdftotext` از Poppler روی سیستم نصب باشد. خروجی متن و PDF به‌صورت محلی و بیرون از مخزن ذخیره می‌شود:

```sh
node scripts/ingest-dena-textbooks.mjs \
  --catalog data/ai/textbooks/catalog-v1.jsonl \
  --book fa-01-1405-1406 \
  --output /srv/dena-private/textbooks
```

برای افزودن کتاب، PDF رسمی و URL آن را از صفحهٔ همان کتاب در chap.sch.ir بردارید و فیلد `pdfUrl` را تکمیل کنید. ابزار دامنهٔ رسمی را بررسی می‌کند، PDF را دریافت و SHA-256 را محاسبه می‌کند، متن را با حفظ صفحه به `pages.jsonl` تبدیل می‌کند و manifest محلی شامل نسخه، زمان دریافت و hash می‌سازد. فایل‌های حجیم یا استخراج‌شده نباید به Git افزوده شوند.

## پوشش فهرست

فهرست با نسخهٔ سال تحصیلی و برای هر کتاب جداگانه گسترش می‌یابد: پیش‌دبستانی؛ پایه‌های ۱ تا ۶ ابتدایی؛ پایه‌های ۷ تا ۹ متوسطهٔ اول؛ پایه‌های ۱۰ تا ۱۲ متوسطهٔ دوم نظری و شاخه‌های فنی‌وحرفه‌ای/کاردانش؛ و نسخه‌های مناسب‌سازی‌شدهٔ آموزش استثنایی. اینها دامنهٔ گردآوری هستند و عنوان‌ها باید مستقیماً از پایگاه رسمی ثبت شوند.
