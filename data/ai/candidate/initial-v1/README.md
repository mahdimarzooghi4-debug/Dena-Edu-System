# بستهٔ نامزد دیتاست اولیهٔ معلم هوشمند دنا

**وضعیت: پیش‌نویس برای بازبینی آموزشی و حقوقی؛ برای آموزش مدل تأیید نشده است.**

این بسته ۲۰ جفت پرسش و پاسخِ متنی را از پنج موضوع موجود در corpus آغازین دنا گردآوری می‌کند. ۱۵ رکورد در split آموزش و ۵ رکورد در split اعتبارسنجی هستند. محتوای نامزد از مثال‌ها و مفاهیم تألیف‌شدهٔ دنا الهام گرفته و پاسخ‌نامه یا کلید گزینه‌های تمرین را وارد نمی‌کند.

## چرا ویدئو لازم نیست؟

این batch از corpus متنیِ موجود دنا استفاده می‌کند. ارجاع‌های منبع و نسخه در هر رکورد حفظ شده‌اند. ویدئوهای مؤسسه برای مسیر جداگانهٔ محتوای مجازِ همان دانش‌آموز هستند و شرط آماده‌سازی این بسته نیستند.

## مانع استفاده برای آموزش

- بازبین آموزشی باید درستی پاسخ، سطح دشواری، واژگان فارسی و مناسب‌بودن مثال‌ها را بررسی و ثبت کند.
- بازبین مسئول باید منشأ و مجوز استفاده از sourceها و وضعیت مالکیت خروجی این بسته را تأیید کند.
- بعد از ثبت تأییدهای انسانی و ساخت manifest دارای hash، فایل باید با `scripts/validate-dena-ai-dataset.mjs` بررسی شود.
- این پوشه manifest تأییدشده ندارد؛ validator عمداً آن را به‌عنوان دیتاست آمادهٔ آموزش نمی‌پذیرد.
- ۲۰ رکورد فقط batch آغازین برای بازبینی و توسعه است؛ به‌تنهایی برای ادعای کیفیت یا آموزش/راه‌اندازی مدل کافی نیست.

## قالب رکورد

`records.jsonl` از فیلدهای قراردادی `recordId`, `input`, `target`, `sourceRef`, `sourceVersion`, `split` استفاده می‌کند. دادهٔ شخصی دانش‌آموز، transcript ویدئو، محتوای مؤسسه، پاسخ آزمون و اطلاعات مجوز به این فایل وارد نشده است.
