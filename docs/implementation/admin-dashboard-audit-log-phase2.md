# Admin Dashboard Phase 2

## هدف
تکمیل خانه مدیر بدون تبدیل دنا به مدرسه رسمی.

## داده‌های مجاز
- شمار کاربران بر اساس نقش
- شمار دوره‌ها
- وضعیت نظارت دوره‌ها
- وضعیت تمرین‌ها
- آخرین رویدادهای audit

## داده‌های ممنوع
- پاسخ دانش‌آموز
- اطلاعات خصوصی دانش‌آموز
- OTP و token
- کلید رسانه

## کنترل دسترسی
تمام APIهای این بخش فقط برای membership با نقش admin فعال هستند.
