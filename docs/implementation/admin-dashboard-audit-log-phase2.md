# Admin Dashboard Phase 2

## هدف
تکمیل خانه مدیر بدون تبدیل دنا به مدرسه رسمی.

## داده‌های مجاز
- شمار کاربران بر اساس نقش
- شمار دوره‌ها
- وضعیت نظارت دوره‌ها
- وضعیت تمرین‌ها
- وضعیت ارزیابی‌های یادگیری
- آخرین رویدادهای audit

## داده‌های ممنوع
- پاسخ دانش‌آموز
- اطلاعات خصوصی دانش‌آموز
- OTP و token
- کلید رسانه

## کنترل دسترسی
تمام APIهای این بخش فقط برای membership با نقش admin فعال هستند.

## وضعیت پیاده‌سازی
- migration `0017_dena_admin_audit_logs.sql` جدول audit را به schema و journal
  رسمی اضافه می‌کند؛ فایل draft قدیمی و ثبت‌نشدهٔ `0011_dena_audit_logs.sql`
  به‌دلیل تداخل شماره و enum ناسازگار حذف شده است.
- خانهٔ مدیر شمار نقش‌ها و دوره‌ها، وضعیت نظارت، تمرین چهارگزینه‌ای و
  ارزیابی یادگیری، و ۱۰ رویداد آخر را نشان می‌دهد.
- صفحه و API مستقل گزارش، ۵۰ رویداد آخر را برمی‌گردانند. مسیرهای نقش، نظارت
  و بازبینی تمرین/ارزیابی، رخداد محدود و بدون متن آزاد را در همان تراکنش ثبت
  می‌کنند.
- در production باید دسترسی دیتابیس برای `UPDATE` و `DELETE` جدول audit بسته
  و سیاست قانونی مدت نگهداری مشخص شود؛ در این نسخه پاک‌سازی خودکار نداریم.
