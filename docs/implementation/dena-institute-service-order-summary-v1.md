# خلاصهٔ درخواست‌های خدمات مؤسسه

صفحهٔ درخواست‌های خدمات، از این پس دو بازهٔ صریح دارد:

- شمارنده‌های وضعیت از کل درخواست‌های همهٔ مؤسسه‌های فعالِ حساب گرفته می‌شوند.
- کارت‌های جزئیات همچنان حداکثر ۲۰۰ درخواست آخرند و فقط داده‌های snapshot سفارش را نشان می‌دهند.
- هیچ شناسه، نام یا نتیجهٔ دانش‌آموز به شمارنده یا کارت اضافه نمی‌شود.
- جمع‌ها فقط وضعیت سفارش را می‌شمارند؛ وضعیت «پرداخت‌شده» تنها از رکورد واقعی سفارش می‌آید.
- تأیید رضایت سرپرست فقط وضعیت همان سفارش را به «در انتظار پرداخت» می‌برد و پرداخت یا آغاز خدمت را ثبت نمی‌کند.

API فهرست مؤسسه نیز خلاصه را بازمی‌گرداند تا مصرف‌کنندهٔ داخلی بعدی همان قرارداد را به‌کار ببرد. سهمیه و زمان مصرف هنوز دفتر اجرایی ندارند؛ این مرحله زمان مصرف را جعل یا ثبت نمی‌کند.
