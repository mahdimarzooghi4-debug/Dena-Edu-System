# ADR-0001 — فناوری پیاده‌سازی دنا

**وضعیت:** مورد توافق برای شروع، ۲۰۲۶-۰۹-۲۰. مخزن هنگام تصمیم فاقد کد بود.

- یک برنامهٔ ماژولار: Next.js App Router + React + TypeScript؛ نه شش فرانت‌اند یا میکروسرویس مجزا.
- UI: Tailwind CSS + shadcn/ui، RTL فارسی، فونت Vazirmatn بدنه و Estedad-VF تیتر مطابق Figma. فایل‌های فونت محلی قانونی بعداً افزوده می‌شوند؛ الآن در مخزن نیستند.
- داده: PostgreSQL + Drizzle ORM، migration نسخه‌بندی‌شده پس از قرارداد دامنه.
- ورود: Better Auth؛ SMS/OTP، rate limiting و اعتبارسنجی جلسه **هنوز راه‌اندازی نشده‌اند**.
- فرم‌ها: React Hook Form + Zod. تست: Vitest + Playwright. CI: GitHub Actions.
- همهٔ نقش‌ها از یک هسته استفاده می‌کنند: دانش‌آموز، مؤسسه، ارائه‌دهنده، ادمین، سازمان و خیر. یک ماژول مشترک تیکت: `/support` حساب مجاز، `/admin/support` اپراتور مجاز.
- احراز اختیار در هر عملیات سروری و روی scope حساب/سازمان/مؤسسه/دوره ضروری است. فیلتر/منوی فرانت‌اند کافی نیست.

**هنوز انتخاب نشده:** هاست و region، پیامک، درگاه ویدئو/پخش HLS با لینک زمان‌دار، پرداخت و CDN. دادهٔ مالی باید با رویداد معتبر و بدون ثبت تکراری تطبیق داده شود. هیچ API، schema یا سرویس فعالی در بوت‌استرپ فرض نشده است.

ترتیب اجرا: shell + DS، هویت/مجوز سروری، مسیر دانش‌آموز و دوره، نظارت دوره‌محور، پشتیبانی فنی مشترک، سازمان/خیر، عملیات مالی و QA مجوز/حریم خصوصی.
